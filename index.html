OptimalLineLength

Analyze and visualize optimal line lengths in text content

What is OptimalLineLength?

Typography best practice: The optimal line length for body text is between 50-80 characters per line. This range ensures maximum readability and reduces eye strain.

OptimalLineLength automatically analyzes your text content and provides visual feedback. Lines within the optimal range (50-80 characters) are marked in green, while lines that are too short or too long are marked in red.

Interactive Controls

Try resizing your browser window! The analysis will automatically update to reflect the new line breaks.

Features

  • Zero Dependencies: Pure vanilla JavaScript, no jQuery required
  • Single File: CSS styles are embedded in the JavaScript file
  • Flexible Selectors: Analyze any text elements you choose
  • Configurable: Customize character ranges and behavior
  • Responsive: Automatically updates on window resize
  • Visual Feedback: Color-coded indicators for instant feedback

Usage

Include the script and initialize:

<script src="optimal-line-length.js"></script>
<script>
  // Initialize with default settings
  const oll = new OptimalLineLength();

  // Or customize the configuration
  const oll = new OptimalLineLength({
    selector: 'p, blockquote, h1, h2',
    minChars: 50,
    maxChars: 80
  });
</script>
